# HMTI Polinema — Web & Design System

Website and design system for **HMTI Polinema** — Himpunan Mahasiswa Teknologi
Informasi, Jurusan Teknologi Informasi, Politeknik Negeri Malang.

> Status: research phase. No application code yet.
